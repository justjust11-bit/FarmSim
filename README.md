FarmSim

A small Pico-8 farming simulation demo. Plant seeds, move the player, manage a tiny inventory, and navigate simple menus.

**Quick Start**

- Open the cartridge `0farmsim.p8` in Pico-8 and run it.

**Controls**

- Arrow keys: Move the player
- Z/X (or ❎/🅾): Interact / confirm
- X (or 🅾): Cancel / back

**Features**

- Basic player movement and collision (`2player.lua`, `3movement.lua`)
- Seed planting and simple crop logic (`4seeds.lua`)
- Inventory management (`5inventory.lua`)
- Menus and title screen (`6menus.lua`, `7title.lua`)

**Repository / Cartridge files**

- `0farmsim.p8` - Pico-8 cartridge (main game file)
- `1main.lua` - Game entry and loop
- `2player.lua` - Player state and sprites
- `3movement.lua` - Movement and collision logic
- `4seeds.lua` - Seeds and crop behaviour
- `5inventory.lua` - Inventory system
- `6menus.lua` - In-game menus
- `7title.lua` - Title / splash screen
